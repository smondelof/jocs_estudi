# Jocs d'Estudi

Jocs de reforç escolar per a nens: cada partida és diferent i al final mostra els encerts, els errors i el motiu, i descarrega un informe en text.

Obre `index.html` (o la web publicada amb GitHub Pages) i tria una assignatura.

## Estructura

- `index.html` – portal amb totes les assignatures
- `angles/` – jocs d'anglès
- `catala/` – jocs de català
- `mates/` – jocs de matemàtiques
- `projectes/` – projectes de classe (amb les imatges a `projectes/img/`)

## Afegir un joc

1. Posa el fitxer `.html` del joc dins la carpeta de l'assignatura.
2. Afegeix-lo a la llista `SECTIONS` d'`index.html` (títol, fitxer, descripció).

Per afegir una assignatura nova, crea'n la carpeta i afegeix una secció a `SECTIONS`.
